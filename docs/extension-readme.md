# codex-switch

Switch Codex between your ChatGPT subscription and DeepSeek API models from the
VS Code sidebar. Choose a provider, model and reasoning effort, then apply and
reload VS Code. Start a new Codex conversation after switching.

The rosette-and-gear icon opens the selector. Your existing encrypted key is
reused; a native masked input lets you replace it. No keys are saved in workspace
settings or sent to the webview. DeepSeek API usage is billed separately.

Requires Windows and Python 3.11+ on PATH.

[Providers, version history and downloads](https://github.com/macorisd/codex-switch)
